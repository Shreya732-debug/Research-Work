# Six-case calibration before independent pilot review

Prepared 26 October 2026. This folder belongs to **Shreya732-debug/Research-Work**, which contains the original proposal and pilot evidence. The linked ExecCoDhe/Final-research repository has not been modified by this calibration package.

**Start with the [six-case calibration ZIP](https://raw.githubusercontent.com/Shreya732-debug/Research-Work/main/pilot/calibration/six_case_calibration.zip).** Extract it and double-click `START_HERE.html`. No programming tools or financial qualification are required to begin the source-reading exercise. Its detailed guide explains browser searches, spreadsheet import, the six tasks, answer recording and discussion.

[Read the detailed calibration guide on GitHub](six_case_pack/START_HERE.md). The browser-readable HTML version is inside the downloaded ZIP. The key is deliberately separate: open it after saving first attempts. It is assistant-authored and provisional, not independently certified gold.

The [24-case review ZIP](https://raw.githubusercontent.com/Shreya732-debug/Research-Work/main/pilot/calibration/independent_24_review.zip) excludes the calibration key, draft labels, analyst explanations and system outputs. Both reviewers review the same 24 claims separately; do not divide them into two sets of 12.

`case_assignment.csv` records the 6/24 allocation. The allocation does not alter the original 30 draft labels. All cases remain pilot/development material; shared issuers/documents and prior answer exposure must be disclosed. Calibration discussion cannot be counted as blinded agreement or model evaluation.

After calibration, return each student's preserved first attempt and after-discussion CSV plus the session log. If only one student is available, record solo practice; do not invent a second reviewer. Unresolved financial interpretations remain unresolved or are excluded with reasons. Two trained students reviewing explicit evidence is not expert validation.

This calibration route supersedes the earlier instruction that students must first find a financial expert. A qualified reviewer can still help with difficult cases, but is not a prerequisite for the narrow initial practice exercise.
